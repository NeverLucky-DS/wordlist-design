# Ralph — автономный цикл в этом проекте

Оригинал: [snarktank/ralph](https://github.com/snarktank/ralph). Здесь лежит
копия, адаптированная под правила проекта. Скиллы `/prd` и `/ralph` установлены
глобально (плагин `ralph-skills@ralph-marketplace`) и работают во всех проектах.

## Порядок работы

1. **Спека.** В Claude Code: `/prd` и описать, что нужно. Он задаст уточняющие
   вопросы и сохранит `tasks/prd-<имя>.md`.
2. **Нарезка.** `/ralph` — превращает спеку в `scripts/ralph/prd.json`: список
   мелких историй, у каждой `passes: false`. Одна история = один заход агента
   со свежим контекстом. Если историю нельзя описать в 2–3 предложениях, она
   слишком большая.
3. **Прогон.** В терминале, из корня репозитория:

```bash
./scripts/ralph/ralph.sh 10
```

`10` — потолок итераций. Цикл останавливается сам, когда у всех историй
`passes: true`, или упирается в потолок.

4. **Проверка — в НОВОЙ сессии.** Уставший агент проверяет себя уставшим
   взглядом. Смотреть `git log`, `scripts/ralph/progress.txt` и диффы.

## Что каждая итерация видит

Свежий `claude` с **пустым** контекстом. Память между итерациями — только файлы:

| файл | роль | в git |
|---|---|---|
| `ralph-prompt.md` | инструкции агенту | да |
| `ralph-settings.json` | deny-правила (защита) | да |
| `ralph.sh` | сам цикл | да |
| `prd.json` | список историй + прогресс | нет |
| `progress.txt` | журнал + `## Codebase Patterns` | нет |
| `archive/` | прошлые прогоны | нет |

## Защита

Цикл запускает `claude --dangerously-skip-permissions`, то есть **без единого
запроса разрешений**. Единственная настоящая преграда — `deny`-правила в
`ralph-settings.json`, которые передаются через `--settings`.

Это не формальность. Документация Claude Code:

> Rules are evaluated in order: **deny, then ask, then allow**. […] If a tool is
> denied at any level, no other level can allow it.

> Permission rules are enforced by Claude Code, **not by the model**.
> Instructions in your prompt or `CLAUDE.md` shape what Claude *tries* to do,
> but they don't change what Claude Code *allows*.

Отсюда правило: **всё, что действительно нельзя, должно быть в
`ralph-settings.json`, а не в `ralph-prompt.md`.** Промпт — это пожелание.

Сейчас запрещено:

| правило | зачем |
|---|---|
| `Bash(docker*)`, `Bash(make up/down/restart*)` | в контейнере живут воркеры обогащения; их состояние в памяти процесса, рестарт убивает всех разом |
| `Bash(rm *)` | `enrichment-GOLDEN-*.db` — 126 МБ вне git, восстановить неоткуда |
| `Bash(git push*)`, `Bash(gh *)` | действия наружу — решение владельца |
| `Bash(git reset --hard*)`, `Bash(git clean*)` | уничтожают чужую незакоммиченную работу |
| `Read/Edit(backend/.env)` | ключи API |
| `Edit(…GOLDEN….db*)`, `Edit(backend/app/vocab/vocab_data/**)`, `Edit(backend/data/**)` | боевые БД |

Не покрыто deny-правилами и остаётся риском: `mv` золотой базы (удаление
закрыто, перемещение нет) и миграции Alembic через `make migrate` — в Postgres
лежит `user_word_list`, единственная непроизводная таблица.

## Отличия от апстрима

1. **Промпт в `ralph-prompt.md`, а не `CLAUDE.md`.** Claude Code подхватывает
   любой `CLAUDE.md` рядом с файлами, с которыми работает. Апстримовский
   начинается с «You are an autonomous coding agent… commit ALL changes» —
   попади он в обычную сессию, она начнёт коммитить всё подряд.
2. **`--settings` с deny-правилами** — в апстриме защиты нет вообще.
3. **`claude` запускается из корня репозитория**, пути к `prd.json` и
   `progress.txt` переданы явно. В апстриме агент должен был сам догадаться,
   что файлы «в той же директории, что и этот файл».
4. **Preflight**: git-репозиторий, `jq`, валидный `prd.json`, чистое рабочее
   дерево. Цикл коммитит сам — стартовать поверх незакоммиченных правок значит
   смешать свою работу с его.
5. **Amp убран** — не установлен, а мёртвая ветка в скрипте, который гоняют без
   присмотра, это ловушка.

## Если пошло не так

Каждая история — отдельный коммит на ветке `ralph/<фича>`, в `main` цикл не
коммитит и `git push` ему запрещён. Значит откат локальный и полный:

```bash
git log --oneline main..HEAD
```

```bash
git reset --hard main
```

## Метрика, которую стоит считать

Не токены и не число прогонов, а **цена за один принятый результат**. Если из
десяти историй шесть переделываются руками — цикл не забрал работу, а сделал
вид. Полезно записывать в `info/PLANS.md`, сколько приняли без правок.
